# 달빛암 올리기 가이드

노트북에서 따라 하면 30분 정도 걸려요. 코딩은 필요 없고, 복사·붙여넣기만 하면 돼요.

## 폴더 안의 파일

| 파일 | 하는 일 |
|---|---|
| index.html | 화면 뼈대 |
| style.css | 디자인 |
| main.js | 3D 절, 동자승, 목탁·절·탑돌이 등 모든 기능 |
| config.js | **헬렌 님이 고칠 파일** (Supabase 주소와 키) |
| supabase.sql | 소원 연등 저장소를 만드는 명령 |
| supabase-giwa.sql | 기와 불사(소원 기와) 저장소를 만드는 명령 |
| supabase-visits.sql | 방문 기록(방문자 수 · 머문 시간)과 통계 비밀번호 |
| stats.html | 헬렌 님만 보는 방문 통계 페이지 (dalbitam.vercel.app/stats.html) |
| supabase-lantern.sql | 연등 종류(황금등·지혜등…)와 108배 불 켜기 칸을 추가하는 명령 (supabase.sql 다음에 한 번 실행) |

## 1단계. Supabase 만들기 (실시간 접속 + 연등 저장)

1. https://supabase.com 에서 GitHub나 구글 계정으로 가입해요.
2. **New project** → 이름 `sansa`, 비밀번호 아무거나, 지역은 **Northeast Asia (Seoul)** → Create.
3. 1~2분 뒤 왼쪽 메뉴 **SQL Editor** → **New query** → `supabase.sql` 내용을 통째로 붙여 넣고 **Run**.
4. 왼쪽 아래 **Project Settings → API** 에서 두 가지를 복사해요.
   - Project URL (`https://xxxx.supabase.co`)
   - 초록색 **Connect** 버튼 → `sb_publishable_...` 로 시작하는 공개용 키 (예전 이름: anon public 키)
5. `config.js` 를 메모장으로 열어 두 값을 따옴표 안에 붙여 넣고 저장해요.

> anon public 키는 웹사이트에 공개돼도 괜찮은 키예요. **service_role** 키는 절대 넣지 마세요.

## 2단계. Vercel 에 올리기 (인터넷 주소 만들기)

1. https://vercel.com 에서 GitHub 계정으로 가입해요. (GitHub 계정이 없으면 github.com 에서 먼저 만들어요.)
2. GitHub 에서 **New repository** → 이름 `sansa` → Create.
3. 저장소 화면의 **uploading an existing file** 을 눌러 이 폴더의 파일 5개를 끌어다 놓고 **Commit changes**.
4. Vercel 에서 **Add New → Project** → `sansa` 저장소 **Import** → 설정은 그대로 두고 **Deploy**.
5. 1분 뒤 `sansa-xxxx.vercel.app` 주소가 생겨요. 이 링크를 인스타 프로필에 걸면 끝이에요.

파일을 고치면 GitHub 에 다시 올리기만 하면 Vercel 이 자동으로 새로 배포해요.

## 3단계 (선택). 내 도메인 연결

가비아나 Cloudflare 에서 도메인을 사요 (예: `dalbitam.com`, 연 1~2만 원).
Vercel 프로젝트 → **Settings → Domains** 에 도메인을 넣으면 연결 방법을 알려 줘요.

## 미리 알아 두면 좋은 것

- **무료 한도:** Supabase 무료 플랜은 동시 접속 200명, 초당 메시지 100개까지예요. Pro 플랜(월 25달러)은 동시 500명, 초당 500개예요. 인스타에서 화제가 되어 사람이 몰리면 Pro로 올리고, `roomCap` 을 20~30으로 두어 법당을 잘게 나누는 게 안전해요.
- **법당 나누기:** `config.js` 의 `roomCap`(한 법당 최대 인원)과 `roomCount`(법당 개수)를 바꾸면 돼요. 한 곳이 차면 다음 법당으로 자동 배정돼요.
- **연등 관리:** 이상한 소원이 올라오면 Supabase → **Table Editor → wishes** 에서 그 줄을 지우면 바로 사라져요.
- **혼자 테스트:** `config.js` 를 비워 두면 '혼자 수행 모드'로 열려요.
- **조작:** 화면을 누르면 걸어가요. 끌면 둘러보고, 두 손가락으로 확대·축소해요. 다른 동자승을 누르면 그 사람에게 합장해요. 연등을 누르면 소원이 보여요.

## 기능 목록

- 장소: 마당, 대웅전(안에 들어갈 수 있음), 석탑, 산신각, 공양간, 범종각, 산책길(숲·계곡)
- 대웅전: 목탁, 절하기(108배 카운트), 향 피우기. 아주 넓은 법당(30×24, 방석 77개), 통일대불을 참고한 금동 좌상(항마촉지인 · 투각 두광), 부처님 뒤 바위 석굴, 양옆 계단 단과 벽을 따라 앉은 금빛 꼬마 동자승 30여 명
- 공양미: 대웅전에서 복전 10닢으로 공양미 한 되를 올리면 불단 앞에 쌀자루가 쌓여요
- 기와 불사: 기와에 소원(20자)을 적으면 법당 앞 너럭바위의 기와 단에 쌓여 모두에게 보여요
- 대웅전 둘러보기: 화면을 끌면 법당 안 사방을 둘러보고, 두 손가락으로 가까이 · 멀리 볼 수 있어요
- 함께 수행하는 동자승: 빈 방석에 같은 법복을 입은 동자승들이 앉아 절하고, 내가 절하면 따라 절해요 (접속자 수에는 포함되지 않아요)
- 계조암 풍경: 법당 뒤 화강암 바위 무리와 살짝 흔들리는 흔들바위, 바위 틈 소나무, 법당 앞 너럭바위
- 석탑: 탑돌이 (자동으로 한 바퀴)
- 산신각: 산신 기도, 칠성 기도(북두칠성이 반짝여요), 초 켜기
- 공양간: 절밥 4가지, 차 마시기
- 공통: 합장 인사·맞합장, 염주 108알, 소원 연등, 범종, 염불 듣기
- 소원 연등: 황금등(재물)·지혜등(합격)·건강등·인연등·소망등 5가지. 소원 글을 보고 종류를 자동으로 골라 줘요. 새 연등은 불이 꺼진 채로 걸리고, 대웅전에서 108배를 마치면 내 연등에 불이 켜져 모두에게 밝게 보여요.
- 자연 소리: 바람, 계곡물, 새소리, 풍경, 효과음 크기 조절
- 실시간: 같은 법당 사람의 위치·동작이 보이고, 인사를 주고받아요. 향과 초는 한 사람이 켜면 모두에게 보여요.
